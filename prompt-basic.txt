we need 2 main components:
1. Collector Script (`collector.py`):
Connects to the ZAP API using the `zaproxy` client.
    - Initializes a `ChromaDBVectorMemory` instance. This will serve as the central knowledge base for the RAG agent.
    - Uses the `SimpleDocumentIndexer` class (provided in the documentation) to index a baseline of security knowledge (e.g., OWASP Top 10 articles, articles about hardcoded secrets).
    - Enters a polling loop to continuously fetch new request/response pairs from the ZAP history.
    - For each new request, it adds the request details (URL, method, headers, body) as a new document into the `ChromaDBVectorMemory`.

2. The RAG Security Agent:
- Memory Initialization:
    - The agent will connect to the same persistent `ChromaDBVectorMemory` instance used by the collector script. This ensures it has access to both the baseline security knowledge and the live traffic data.

- Agent Definition (`rag_agent.py`):
    - Define an `AssistantAgent` named `SecurityAnalysisAgent`.
    - The agent's `memory` parameter will be configured with the `ChromaDBVectorMemory` instance.
    - System Message: The agent's system prompt will instruct it to act as a security analyst. The prompt should guide it to use the provided context (retrieved from memory) to answer questions about potential vulnerabilities in the captured web traffic.

in terminal we run `poetry run python zap_rag_agent/main.py`.
This script will contain the `SecurityAnalysisAgent` and a `UserProxyAgent` to ask questions.

The user can now ask the `SecurityAnalysisAgent` questions like:
